How to join
  1. Press Start and wait about 1–2 minutes until the status shows ONLINE.
  2. Open Minecraft (Bedrock edition) and tap Play.
  3. Go to the Servers tab, scroll down, tap Add Server.
  4. Enter any name, paste the Server Address shown above, keep port 19132, tap Save.
  5. Join the server. Your gamertag must be on the allow-list or you get “not invited”.
  6. The address can change each time the server starts — check this page before joining.
  7. When you're done, press Stop (or it stops by itself after everyone's been gone a while).
